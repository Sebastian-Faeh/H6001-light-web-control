Notes

Unofficial project, not affiliated with or supported by Govee. Govee is a trademark of its owner.

Close the Govee app first; the bulb accepts only one connection at a time. Only one page of this site holds the bulb: a newly opened page makes older ones disconnect.

Light: after "On" the page reads brightness and colour from the bulb and moves the sliders. In a scene (sunrise or sunset) the bulb reports no colour, so only the brightness slider follows. Choosing a colour ends the scene.

Timer: saving sets the bulb clock, writes the timer to timer slot 1 (start and duration), selects the scene and reads the timer back as a check. Scene "On" sets a plain colour with the slider values instead of an animation. After saving, the bulb runs the timer on its own; the page does not need to stay connected. The timer repeats every day and has no weekday field. Short durations (15 minutes) are untested.

Sunset now selects the sunset scene and switches the bulb on. Link with the action preselected: add ?action=sunset to the address (for example as a home-screen shortcut); the page then starts the sunset as soon as it is connected.

Alarm: wake time, duration, scene and weekdays are stored in this browser (localStorage) and are not sent anywhere. The bulb cannot do weekdays, so the page enables the bulb timer for the next start if that weekday is selected and disables it otherwise. It checks at every connection, when the page becomes visible again and once a day after 02:00 (hourly timer) while the page is open; it does not run when the page is closed or the browser is asleep, and background timers may be delayed or stopped. With 1 to 6 weekdays selected the page must stay open (the heading shows a note); it asks before being closed, but Chrome on Android shows no question when a tab is closed. While a window is running nothing is changed. While the bulb is lit the scene is not changed. A manual Save is overwritten by the alarm at the next check while the alarm is active. Known problem: tests on the bulb (Oct 2026) showed that a record with enabled = 0 still starts its scene, and that it is stored next to, not instead of, the enabled record. Skipping unselected weekdays therefore does not work; see PROTOCOL.md.

The bulb receives the time at every connection. Its own clock cannot be read, so the page does not compare times but always sets it. After the daylight-saving change on 25 Oct 2026, open the page once and connect.

On load the page connects to the last used device if Chrome allows it. Otherwise the first tap on the page starts the search (Chrome only allows the search after a touch).

Behaviour at the end of the timer window (switch off or not) has not been observed. Protocol details are in the source code.

Tips

Routine instead of an open tab: the alarm check runs at every connection. A routine on the device (for example a scheduled routine that opens a web address) can open this page at night, e.g. at 02:05, so the weekday alarm does not need the tab open all day. The alarm must be active, the bulb in range and not connected to another app. Whether it works with the screen off is untested.

One-tap sunset: add ?action=sunset to the address and use Chrome's "Add to Home screen".
