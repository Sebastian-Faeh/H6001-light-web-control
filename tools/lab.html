H6001 Lab Tool

For exploring the protocol, not for daily use. Raw commands can change settings of the bulb; the Govee app can correct them again. Close the Govee app first (the bulb accepts only one connection).

Not connected.

Read (like the Govee app when it opens)

Timer queries: aa 0a 00 and aa 0a 01. Each reply holds 5 data bytes.

Write timers

Format: 33 0a <id> <start h> <start min> <end h> <end min> <enabled>. The official app writes both ids one after the other, about 1 s apart, and sends the scene afterwards. In tests the bulb accepted writes to id 1 but silently discarded writes to id 0, while acknowledging both. Always read back.

Set the bulb clock

The official app sends this at every connection.

Switch

04 00 is confirmed as sunrise (app label and bulb behaviour). 04 01 is presumably sunset (sent by the app after choosing sunset, not seen running).

Raw command

Hex bytes without checksum. The tool pads to 19 bytes and appends the XOR byte.
