H6001 Timer Test

Guided experiments for the open timer questions (see PROTOCOL.md). They overwrite timer records of the bulb; afterwards set your real timer or alarm again on the main page. Close the main page and the Govee app first: the bulb accepts one connection. Use Chrome.

Guided test
Runs the timer experiments step by step and asks you what it needs to know. Takes about 15 minutes.
Manual tools

Read

PositionIdStartEndEnabled

Position = the order of the bulb's replies to aa 0a 00 and aa 0a 01. The id is the byte inside the reply.

Test 1: which record does a write replace?

Reads the timers, writes three records one after the other (id 1, id 1, id 0) and reads after each write. The times will make the bulb run its scene tonight unless you overwrite them. Note which of them actually start.

Test 2: does "enabled = 0" stop the start?

Sets the clock, writes one record that starts in a few minutes, reads it back and then disconnects. Stay away from the bulb page and do not reconnect until the start time has passed. Then tell Claude whether the bulb lit at the start time. The bulb should be off.
